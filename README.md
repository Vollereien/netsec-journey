### 二进制与十进制

#### 一、先背这 8 个数

```
128  64  32  16  8  4  2  1
```

记忆方法：**从右往左每次翻倍；从左往右每次减半。**

为什么是这 8 个？因为 IP 地址每一段是 8 位二进制，每一位对应一个权重：

| 位序（从右往左，从 0 开始） | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|---|---|
| 权重 | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

> ⚠️ 说法纠正：不是"二进制从零开始计数"，是**位序从 0 开始编号**。最右边是第 0 位，往左依次 +1。

#### 二、二进制 → 十进制：看到 1 就加，看到 0 就跳过

**核心口诀：1 = 拿这张钞票，0 = 不拿，最后加起来。**

例：`11000000`

```
1   1   0   0   0   0   0   0
↓   ↓
128 64                          （拿 128 和 64，其余不拿）
```

128 + 64 = **192**

> ✅ 这就是子网掩码 `/26 = 192` 的由来。

**提速巧劲：0 多的时候用减法**

`11111000` —— 与其加五个数，不如想：全 1 是 255，末尾三个 0 少了 4+2+1=7
→ 255 − 7 = **248**

**0 超过 4 个时，减法比加法快。**

#### 三、十进制 → 二进制：减得动写 1，减不动写 0

**大数：从 128 开始往下减**

例：`178`

```
178 − 128 = 50   够  → 1
 50 −  64      不够  → 0
 50 −  32 = 18   够  → 1
 18 −  16 =  2   够  → 1
  2 −   8      不够  → 0
  2 −   4      不够  → 0
  2 −   2 =  0   够  → 1
  0 −   1      不够  → 0
```

结果 = **10110010** ✓（验算：128+32+16+2 = 178）

**小数：先找最接近的 2 的次方，从它开始减**

例：`56`

最接近 56 的是 32，从 32 开始：

```
56 − 32 = 24   够  → 1
24 − 16 =  8   够  → 1
  8 −  8 =  0   够  → 1
  0 −  4      不够  → 0
  0 −  2      不够  → 0
  0 −  1      不够  → 0
```

结果 = **111000**

#### 四、顺手：十六进制（4 位一组，不用算）

16 = 2⁴，所以**一个十六进制位 = 正好 4 个二进制位**，只需查表、不用算。

`10110010` → 分组 `1011` `0010` → `B` `2` → **0xB2**

| 二 | 十六 | 二 | 十六 |
|---|---|---|---|
| 1010 | A | 1110 | E |
| 1011 | B | 1111 | F |
| 1100 | C | 1000 | 8 |
| 1101 | D | 0000 | 0 |

锚点记三个就够：**A=1010、8=1000、F=1111**，其余加减 1 推出来。
